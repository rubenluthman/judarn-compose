# Judarn Compose (`judarn-compose`)

Swiss-modernist design system foundation for Android (Jetpack Compose & Compose Multiplatform).

## Core Invariants
- **Perceptual OKLCh Mathematics**: Calibrated Dual-Tier Carbon dark theme (#171717 / #222222) and warm modernist paper (#F5F3EE).
- **8dp Macro / 4dp Micro Grid**: Strict geometric rhythm.
- **Decoupled 48dp Touch Targets**: Compact modernist visual box wrapped in Material Design 3-compliant 48dp touch envelopes.
- **Ripple Suppression**: Pure instantaneous modernist color inversion without Google Material 3 circular ripple blooms.
- **Continuous 1dp Hairlines**: 1dp interior cell boundaries, 2dp bold header baselines, 0-radius rectangular geometry.
